产品介绍

网页上的灵感，不该一闪就没

灵感易忘

读到一半忽然有想法，关掉标签页就找不回当时的上下文。

收藏夹太杂

收藏夹塞满却找不到当时为什么存，标题都对不上心里那句话。

PageMemo 把便签钉在「这一页」上：你在哪儿读，就在哪儿记。 再次打开同一网址，侧边抽屉里的备忘原样回来。

不必新建文档、不必切换应用。勾选完成、全局翻看、导出备份—— 数据只存在你的浏览器本地，不上传、不账号。

适合阅读笔记、任务备忘、研究摘录，以及任何「跟这个页面绑定才有意义」的碎想法。

核心功能

记下来，找得回，管得住

从随手记到导出备份，覆盖日常网页备忘的完整闭环。

  • 随手记

    任意网页右下角「记一笔」，灵感当场落纸，不用切走。

  • 按页面归位

    便签与当前 URL 绑定，下次打开同一页，备忘自动出现。

  • 完成勾选

    读完、办完就勾掉，待办与已完成一眼分开。

  • 全局管理页

    工具栏一键打开全部便签，按站点分组浏览。

  • 搜索筛选

    按内容、标题搜索，按未完成 / 已完成筛选。

  • 导出备份

    一键导出 JSON 或 TXT，换机或归档心里有底。

  • 纯本地存储

    数据仅保存在本机浏览器，不上传服务器，不依赖账号登录。

安装步骤

四步加载，即可使用

当前为开发者模式安装，打包 zip 后按下列步骤操作。

  1. 1

    解压下载包

    将 page-memo.zip 解压到任意本地文件夹，保留完整目录结构。

  2. 2

    打开扩展程序页

    在地址栏输入 chrome://extensions 并回车（Edge 可用 edge://extensions）。

  3. 3

    开启开发者模式

    打开页面右上角「开发者模式」开关。

  4. 4

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择解压后的 extension 文件夹即可。

开始在网页上贴便签

本地存储、不上传，解压加载即可用。
